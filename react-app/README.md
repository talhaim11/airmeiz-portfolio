# AIRMEIZ React App

React + TypeScript + Tailwind CSS app with the animated shader background component.

## Setup

```bash
cd react-app
npm install
```

## Run

```bash
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
```

## Project Structure

- `src/components/ui/` - UI components (shadcn-style)
- `src/components/ui/animated-shader-background.tsx` - Aurora shader background
- `src/index.css` - Tailwind + custom styles

## Adding shadcn components

To add more shadcn components later:

```bash
npx shadcn@latest add <component>
```
