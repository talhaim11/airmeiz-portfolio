# Local Development (React Only)

## Correct App

Use the React app in `react-app/` only.

## Start

From repository root:

```powershell
npm run dev
```

Or:

```powershell
cd react-app
npm run dev
```

## URL

- `http://localhost:5173`

## Important

- Do not run static server commands for the old HTML site.
- Legacy static files are isolated under `legacy-static/public-legacy/`.
